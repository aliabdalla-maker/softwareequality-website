Cookie Policy

Equality Software Ltd · Company No. 15006381 · Last updated: October 2026

1. Summary

softwareequality.com does not set any cookies. We do not use Google Analytics or any advertising or tracking cookies, so you will not see a cookie consent banner on this site.

2. Browser storage we use

A few small items are kept in your browser's own storage (not cookies) so the site works as you expect. They never leave your device and contain no personal information:

  • se-assistant-size (local storage): remembers the size you chose for the AI assistant window.
  • Session items (session storage): remember, for the current visit only, whether you have already seen the assistant greeting. They are deleted when you close the tab.

3. Third-party services

Some features use other services, which apply their own policies when you use them:

  • Stripe: if you pay for a bootcamp, you are taken to Stripe's checkout page, which may set its own cookies for security and fraud prevention.
  • Booking calendar: if a booking calendar is shown on the Book a Call page, the calendar provider may set cookies inside that calendar.
  • Web3Forms: receives the details you submit in our forms and passes them to us. It does not set cookies on this site.

4. Changes to this policy

If we start using cookies, we will update this page and ask for your consent first where the law requires it.
