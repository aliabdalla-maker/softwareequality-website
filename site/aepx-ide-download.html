Download AEP-X Agentic IDE

Agents plan your software, music, video, film, multimedia and social media work and its deployment, you approve every step, and each action is audited. Includes Media Studio, editor plugins and the Agentic SDK. One account works on every device.

Free for 30 days, with ads. Then £4.99/month with 95% fewer ads, or keep using the free plan with ads. Cancel any time. One subscription covers Windows, Mac, Linux, Android, iPhone and the web.

Windows PC

The desktop app for Windows 10 and 11 (Intel, AMD and Arm). It opens in its own window and appears in the Start menu and taskbar.

Download for Windows (.exe)Portable version (no install)Install from your browser

If Windows shows "Windows protected your PC", choose More info, then Run anyway. The installer is from Equality Software Ltd.

Mac

For macOS 12 or later. Choose Apple silicon for M1, M2, M3 and M4 Macs, or Intel for older Macs (Apple menu, About This Mac shows which).

Download for Apple siliconDownload for Intel Macs
  1. Open the downloaded file and drag AEP-X IDE into Applications.
  2. The first time you open it, if macOS says it cannot check the developer, open System Settings, Privacy & Security, and choose Open Anyway.
  3. Sign in or create your account.

Linux

For Ubuntu, Debian, Fedora, Red Hat, openSUSE, Arch and other distributions, on x86-64 or Arm64 (for example Raspberry Pi 4 and 5).

AppImage (x86-64)AppImage (Arm64)Ubuntu / Debian (.deb)Ubuntu / Debian Arm64 (.deb)Fedora / Red Hat / openSUSE (.rpm)Any distribution (.tar.gz)Any distribution Arm64 (.tar.gz)
  1. AppImage: make it executable (right-click, Properties, Allow executing, or chmod +x), then double-click it.
  2. .deb: sudo apt install ./AEP-X-IDE-Linux-amd64.deb. .rpm: sudo dnf install ./AEP-X-IDE-Linux-x86_64.rpm.
  3. .tar.gz: unpack it and run aepx-ide from the folder.

Unix (FreeBSD, OpenBSD, NetBSD, illumos, Solaris, AIX)

There is no native desktop build for these systems, because the desktop framework the app uses does not support them. Use the full IDE in Firefox or Chromium instead; nothing is lost.

Open the web appLinux .tar.gz for FreeBSD's Linux layer
  1. In Firefox or Chromium, open the web app and sign in.
  2. In Chromium, choose Install from the address bar to give it its own window.

On FreeBSD, the Linux build may also run under the Linux compatibility layer (linux64). That route is not officially supported.

Android: Google Play

Android: direct download (APK)

For Android 8 or later, with or without Google Play. Pay by card on the web.

Download APK (available soon)
  1. Open the downloaded file.
  2. If asked, allow your browser to install unknown apps.
  3. Tap Install, then sign in with your account.

iPhone and iPad

Install from Safari in seconds, with no App Store needed. It opens full screen from your Home Screen like any app.

Install on iPhone or iPad
  1. Open this page on your iPhone or iPad in Safari and tap the button.
  2. Tap Share, then Add to Home Screen.
  3. Open AEP-X IDE from your Home Screen and sign in.

An App Store version is coming. Your account and projects stay the same.

Editor plugins: VS Code and JetBrains

Use the AEP-X agents inside the editor you already use: VS Code, IntelliJ IDEA, PyCharm, WebStorm and the other JetBrains IDEs.

VS Code extension (.vsix)JetBrains plugin (.zip)
  1. VS Code: Extensions, the ... menu, Install from VSIX, then choose the file.
  2. JetBrains: Settings, Plugins, the gear icon, Install Plugin from Disk, then choose the file.
  3. Sign in with your AEP-X account when asked.

Agentic SDK (Python)

Build your own governed agents and automations on AEP-X: plans, approvals and the audit trail from your own code. Python 3.10 or later.

Download the SDK (.zip)
  1. Install it with pip install AEP-X-Agentic-SDK-Python.zip.
  2. Then import aepx in your code.

Web app (any computer)

Nothing to install. Works in Chrome, Edge, Safari and Firefox on Windows, Mac, Linux, Unix and Chromebooks. In Chrome or Edge choose Install to add it to your desktop.
